# Connector optics display demo

This sketch plays the rendered 240 × 240 RGB565 art from the ESP32-S3's
`ffat` partition. It is a **simulated display demo**: the pin states and
voltage shown in the frames are artwork, not measurements. The live tester
firmware and its saved NVS calibration were backed up before installation.

The asset is generated by `scripts/build_connector_device_demo.py`. It contains
500 main frames at 50 frames per second plus 100 frames of the alternate pair.
Both powered states use the same cold-to-gold directional flash. Frames are
zlib-compressed RGB565 XOR deltas, with keyframes at
the start of each independently looped section.

The default `full` mode loops the 10-second sequence. Send a word
followed by a newline over the 115200-baud serial port to select a section:

- `idle`: orange orientation datums, 2.8-second loop
- `helix`: recognized pair, static red Allied Vision mark, electrical helix,
  and gold flash, 1-second loop
- `storm`: alternate pair, crossed mark, and the same gold flash, 2-second loop
- `full`: complete 10-second sequence

The player decodes the next frame on the second CPU core while the LCD
transfers the current frame. It reports measured frame rate, average decode
time, and display transfer time every five seconds. The recognized-pair
loop measured 49.5–50 fps on the connected tester; the full sequence measured
about 47 fps because its transition frames are more expensive.

The build uses the `esp32:esp32:esp32s3`
board with 16 MB flash, enabled PSRAM, and the `app3M_fat9M_16MB` partition
scheme. The app is written at `0x10000`; the asset is written at `0x610000`.
The previous gold flash update wrote only the asset at `0x610000`, leaving the
app and NVS at `0x9000` intact. The current rendered art adds the tapered
enamel band and static red logo. Its flashed asset and verification record
are in `output/connector-finished-ui-2026-10-22/`. The original live app backup
is in `output/connector-device-demo-2026-10-22/`; the previous gold flash
update evidence is in `output/connector-gold-flash-2026-10-22/`.
