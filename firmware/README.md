# Connector display firmware

The live voltage-measurement firmware for the actual 12 V Rev A PCB is now in
`Tester12V/`. Its wiring, calibration and first-article procedure are in
[`../hardware/rev-a/README.md`](../hardware/rev-a/README.md). The
`ConnectorDisplay` material below remains the earlier animation demo.

Target: Waveshare ESP32-S3-LCD-1.28 (non-touch), ESP32-S3R2, 16 MB flash and 2 MB QSPI PSRAM. This is the match inferred from the supplied product description and detected chip/memory.

Display: 240 × 240 GC9A01, SPI clock GPIO10, MOSI GPIO11, CS GPIO9, DC GPIO8, reset GPIO12, backlight GPIO40. The firmware alternates the green shimmering success animation and the red shimmering/pulsating failure animation every 4.8 seconds, at 10 frames per second and 80% backlight brightness. This is a visual demo using example pin locations, not live voltage detection.

Driver source: Waveshare official demo, downloaded from https://files.waveshare.com/wiki/ESP32-S3-LCD-1.28/ESP32-S3-LCD-1.28-Demo.zip. Original notices remain in the copied driver files. Board documentation: https://docs.waveshare.com/ESP32-S3-LCD-1.28.

Build uses installed Arduino ESP32 core 3.3.7:

```sh
"/Applications/Arduino IDE.app/Contents/Resources/app/lib/backend/resources/arduino-cli" compile \
  --fqbn esp32:esp32:esp32s3:FlashSize=16M,PSRAM=enabled,CDCOnBoot=default,PartitionScheme=app3M_fat9M_16MB \
  --output-dir firmware/build firmware/ConnectorDisplay
```

Regenerate the image with `node scripts/make_lcd_image.cjs`. RGB565 bytes are stored in flash and copied to a 115,200-byte RAM buffer for transfer. No network connection or external asset loading is required. UART logs at 115200 baud report DISPLAY_READY and a heartbeat every five seconds. Those logs confirm program execution and display transfer, not physical visual output; the screen is write-only.

## Flashing this USB bridge

Unpaced esptool 5.1.0 and 4.8.1 writes failed with packet/checksum errors. `scripts/flash_serial.py` sends 64-byte chunks with wire-time pacing; the stub then uploads successfully. Local tooling: `firmware/.venv` with `esptool==4.8.1` and pyserial.

```sh
firmware/.venv/bin/python scripts/flash_serial.py \
  --port /dev/cu.usbmodem58760426031 --baud 115200 write_flash \
  --flash_mode dio --flash_freq 80m --flash_size 16MB \
  0x0 firmware/build/ConnectorDisplay.ino.bootloader.bin \
  0x8000 firmware/build/ConnectorDisplay.ino.partitions.bin \
  0xe000 /Users/petter/Library/Arduino15/packages/esp32/hardware/esp32/3.3.7/tools/partitions/boot_app0.bin \
  0x10000 firmware/build/ConnectorDisplay.ino.bin
firmware/.venv/bin/python scripts/check_display.py
```

The check resets the board into the application and records a 12-second startup log in `firmware/boot-log.txt`.

## Animation assets

`ConnectorAnimation.h` contains lossless RGB565 delta frames generated by `scripts/build_lcd_animations.py` from the two 48-frame PNG sequences. All frames are round-trip checked by the generator. The 96-frame data is 1,486,182 bytes, with one 115,200-byte framebuffer. `DEV_SPI_Write_nByte` uses `writeBytes` rather than `transfer` to preserve the framebuffer between delta updates.

Build uses the 3 MB application / 9.9 MB FATFS partition scheme on 16 MB flash. Serial logs identify each displayed state, frame counts, rendering time, and available heap. No network or sensor input is involved in the demonstration.

## Voltage rise/drop demonstration

The current demo simulates 0 V, a linear rise to 24 V over 1.2 seconds, a brief hold, then a drop to 0 V on the next 100 ms display frame. Particle density/brightness follows the simulated voltage and the stream disappears at zero. The ring remains the machine's independent pin-pair verdict. No voltage is being measured in this demo; real fall time depends on the power circuit and sampling.

Regenerate both states using `python3 scripts/animate_electrons.py --voltage-demo` and `python3 scripts/animate_electrons.py --fail --voltage-demo`, render the two frame folders, then run `scripts/build_lcd_animations.py`. Device logs report `SIMULATED_VOLTAGE` stages, including HOLD at 24000 mV and DROP at 0 mV.

The paced flashing wrapper was also successfully verified at 460800 baud for the voltage-demo firmware; the main image hash passed after upload. The serial console remains at 115200 baud.

## Frameless label colors

Current labels use warm amber `#FFD77A` for voltage and icy cyan `#8CE7F4` for GND. Opaque label plates are removed. A 5-unit dark glyph outline (about 1.2 pixels total at 240 × 240) preserves readability over the metallic surfaces. Leader lines terminate outside the text bounds. Voltage behavior and green/red animation timing are unchanged.
