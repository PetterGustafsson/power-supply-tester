Description
The R05C05TE05S is a low cost, low profile, 0.5W SMD isolated DC/DC single output converter with               0.5 Watt
4.5-5.5V input range and a semi-regulated 5V output. There is no minimum load requirement which
is ideal for applications which switch into very light load operation modes. The device is also able to        16-Pin SOIC
deliver a 600mW for applications requiring additional power for short peak operation modes. Standard
isolation is 3kVDC/1min, and the operating temperature is from -40°C up to +125°C with derating.
The fully-automated design which is equipped with short-circuit, over-current, and over-temperature
                                                                                                               Single Output
protection ensures the highest reliability in applications such as communication, current sensing, and
COM port isolation.
