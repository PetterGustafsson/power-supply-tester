# Finished product render

The approved studio composition shows the assembled I15 tester, complete black
cable and chrome HR10A connector. The camera, enclosure and cable stay fixed
while the actual LCD artwork animates through all three modes.

The loop holds idle for three seconds, seats across one second, shows the
recognized pair for three seconds and another pair for three seconds, then
releases across one second. The recognized emblem remains static red; the
other-pair emblem is muted and crossed. The release retains the other-pair
polarity and muted emblem until they disappear.

Voltage and polarity are illustrations from the approved artwork, not recorded
measurements. No device connection or firmware operation is used to render this.

## Sources and rendering

- Current I15 base, top and crown: [preserved printable meshes](../../case-cad/current/).
- Display module, rubber feet, cable and connector: preserved world-frame
  reference meshes in [the I9 CAD exports](../../case-cad/cad_I9/stl/).
- LCD motion: `complete-experience-240.webp` and
  `other-pair-thunderstorm-240.webp` in
  [the approved artwork export](../connector-finished-ui-2026-10-22/).
- The other-pair release is generated by
  [build_connector_optics.py](../../scripts/build_connector_optics.py), with its
  preview pair set to `(3, 7)`.

The Blender scene assembles the I15 print meshes at their original scale,
restores the top's 6.5 mm split offset and the crown's display-plane orientation,
and maps the native 240 × 240 artwork to the circular active LCD. Cycles renders
the studio at 128 samples with AgX color management and denoising. A transparent
LCD pass preserves the crown's occlusion for every animated frame. GIF local
color tables give the display its own fixed palette, and only the LCD rectangle
updates between frames; the exterior cannot flicker.

## Regenerate

Requires Blender 4.2, the repository's Python dependencies and `rsvg-convert`
from librsvg. Run from the repository root:

```sh
blender --background --python scripts/build_product_hero.py -- --final --scene-only
python scripts/build_product_hero_animation.py prepare --final
blender --background output/product-render/product-hero.blend \
  --python scripts/render_product_hero_screen.py
python scripts/build_product_hero_animation.py encode
```

The intermediate frames are written to the ignored
`output/product-render-frames/` directory. The encoder validates dimensions,
all 275 frames, the 11-second duration, infinite looping, and the update rectangle
of every frame. Export hashes and source references are saved in the manifest.

For a smaller review render, omit `--final` in the first two commands. The
camera and materials are unchanged.
